# Java Calculatrice

A console-based calculator developed in Java as part of my DSI studies.

## Features

- Addition of two integers
- Maximum and minimum of two integers
- Minimum of three integers
- Greatest Common Divisor (PGCD)
- Minimum value in an array
- Search for an integer in an array
- Sum of array elements
- Interactive menu using `switch`

## Technologies

- Java
- Apache NetBeans
- Java Scanner
- Arrays and Methods

## Concepts Practiced

- Conditions (`if / else`)
- Loops (`for`, `while`, `do while`)
- Methods and method overloading
- Arrays
- User input
- Basic algorithms

## How to Run

1. Clone this repository.
2. Open the project in Apache NetBeans.
3. Run the `Calculatrice.java` file.
4. Follow the console menu.
